( Go ) Backend

Función ( AuthMiddleware )

Protección de rutas. Además esta función permite la extracción de información de usuario desde la petición.
AuthMiddleware( next http.Handler )

                            mux.Handle("/users", utils.AuthMiddleware(http.HandlerFunc(handler.CallUsers)))

ContextKey ( string )

Las ContextKey indexan información especifica del usuario que realiza una petición.

r http.Request

                            // Id ( Base de datos ) del usuario
                            id := r.Context().Value(utils.UserId).(string)
                            // Name ( Base de datos ) del usuario
                            name := r.Context().Value(utils.UserName).(string)
                            // Grupo de permisos del usuario
                            party := r.Context().Value(utils.UserParty).(string)
                            // Token JWT de autenticidad
                            jwt := r.Context().Value(utils.UserToken).(string)

Función ( LowLevelMiddleware )

No proteje rutas pero si extra información del usuario que realiza la petición.

LowLevelMiddleware( next http.Handler )

                            mux.Handle("/session", utils.LowLevelMiddleware(http.HandlerFunc(handler.CallSession)))

Función ( AddPermissions )

Agregar permisos a las peticiones ( GET, POST, PUT, DELETE, etc... ) Basta con agregar la función al inicio del endpoint para validar la petición del usuario.
AddPermissions( level int, userParty string) (bool, error)
Cuando el nivel de protección es 0 se asume nivel mas alto 4 ( solo admin ). Retornar http.StatusUnauthorized permite que JS notifique al usuario. 

                            ...
                            party := r.Context().Value(utils.UserParty).(string)
                      		valid, err := utils.AddPermissions(0, party)
                      		if err != nil {
                     			log.Printf("Message (%v)", err.Error())
                     			http.Error(w, err.Error(), http.StatusInternalServerError)
                     			return
                      		}
                      		if !valid {
                     			w.WriteHeader(http.StatusUnauthorized)
                     			return
                      		}

Navegación ( GoHome, GoBack, logOut, OnlyRedirect )

Sección de 4 reutilizables JavaScript que permiten redirrección y navegación.

El uso es extremadamente simple; el componente Alpine lo incias en el HTML, los mapeas con minuscula, y llamas a la funcion en mayusculas. Estas funciones ya se encargan de la seguridad y sesión de usuario.
GoHome( ) | Redirecciona a "/home"
GoBack( path string ) | Redirecciona a "path"
LogOut( ) | Redirecciona a "/"
OnlyRedirect( path string ) object | Redirecciona a "path". También devuelve un object con el atributo authError bool. Trabaja en conjunto con AddPermissions. 

                            async goHome() { await GoHome() },
                            async goBack() { await GoBack(path) },
                            async logOut() { await LogOut() },
                            async go...() {
                                const res = await OnlyRedirect(path)
                                this.authError = res.authError
                            },

CRUD ( ReadRecord, CreateRecord, UpdateRecord, DeleteRecord, FetchDataFromResponse )

Todas las funciones CRUD devuelven un object con el atributo authError bool. Trabaja en conjunto con AddPermissions. Si el servicio es asegurado a nivel 4 para todos los endpoints GET( /home, /list, /new, /record, /cualquier otra... ) ( Solo Admin ). No necesitas esperar respuesta en los controladores Alpine.js. Si acaso unicamente en la vista menu de la ruta "/home". 

                            // Cuando todo el servicio es nivel 4.
                            async createRecord() {
                            const record = { }
                            // Notar que no se espera respuesta y se utiliza un "await" directo
                            await CreateRecord(path, redirect, {method: "POST", body: JSON.stringify(record)})
                            },

                            async openRecord(id) { await ReadRecord(id, path) },

                            async updateRecord() {
                                const record = JSON.stringify({ })
                                await UpdateRecord(path, redirect, {method: "PUT", body: JSON.stringify(record)})
                            },

                            async deleteRecord() {
                                const record = JSON.stringify({ })
                                return this.invalid = await DeleteRecord(
                                    path, redirect, {method: "DELETE", body: JSON.stringify(record)}
                                )
                            },

                            async loadRecords() {
                                const data = await FetchDataFromResponse(path, options)
                            },
CreateRecord( path string, redirect string options object ) object - Crear un registro.
ReadRecord( id int path string) object - Redireccionar a la vista de un registro.
UpdateRecord( path string, redirect string options object ) object - Actualizar un registro.
DeleteRecord( path string, redirect string options object ) object - Eliminar un registro.
FetchDataFromResponse( path string options object ) object - Solicitar data a un endpoint.
Si se desea manejar niveles de acuero al permiso de usuario, debe esperarse el objeto con la validación de autorización. Notar que la funcion FetchDataFromResponse NO devuelve el objeto ( object.authError ), en su lugar devuelve un objeto de data desde el backend. 

                            // Manejando solicitudes segun niveles de permisos.
                            async createRecord() {
                                const record = { }
                                const res = await CreateRecord(path, redirect, {method: "POST", body: JSON.stringify(record)})
                                this.authError = res.authError
                            },

                                this.hasNextPage = data.hasNextPage
                                ...
                            },

Integer - Float - MXN Currency

ValidateIntegerStringToInteger( str string ) float - Mantiene unicamente caracteres númericos, y cast a integer.
ValidateFloatStringToFloat( str string ) integer - Mantiene unicamente caracteres númericos, y cast a float.
FormatterMXN.format( value float ) string - Da formato de moneda $0.00. 

                            const number = ValidateIntegerStringToInteger(this.quantity)

                            const payment = ValidateFloatStringToFloat(this.dailyPayment)

                            currency(str) {
                              const float = ValidateFloatStringToFloat(str)
                              if (isNaN(float)) { return '' }
                              const money = FormatterMXN.format(float);
                              if (money === '$0.00') { return ''}
                              return money
                            },

Many2One ( Selection )

( GO ) procesa la data desde service el cual sube a la capa de endpoints. Desde ahi el ( JS ) puede llamar a la data.
En ocasiones la data de relación podras obtenerla desde la base de datos, en otras ocaciones se extra la data desde un JSON o cualquier otro medio. Para este ejemplo pretendemos que se extra data desde JSON.
Supongamos el siguiente JSON [ { "code": 1 }, { "code": 2 }, ... ] 

                            // 1. TIPADO
                            type Indentifiers struct {
                                Code int `json:"code"`
                            }
                            // Notar que un solo 'Many2One' puedes mandar mas slices de selección.
                            type Many2One struct {
                                IdentifiersRecord: []*Identifiers `json:"identifiersRecords"`
                            }
                            // 2. LEER Y DECODIFICAR
                            file, err := os.Open(path)
                           	if err != nil {
                          		return nil, err
                           	}
                            defer file.Close()
                           	var many2one Many2One
                           	if err := json.NewDecoder(file).Decode(&many2one.IdentifiersRecords); err != nil {
                          		return nil, err
                           	}
                            // 3. RETORNAR EN ENDPOINT
                            w.Header().Set("Content-Type", "application/json")
                      		w.WriteHeader(http.StatusOK)
                      		json.NewEncoder(w).Encode(many2one)
