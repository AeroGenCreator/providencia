{{ .Title }} Saavedra

Saavedra no pretende ser un framework. En su lugar, es un conjunto de funciones, fragmentos de código y flujos organizados por capas que, en conjunto, permiten construir una aplicación web.

La razón es simple: los asistentes de IA son cada vez más utilizados para la escritura de código. Por ello, mantener flujos de código explícitos permite que tanto los desarrolladores como las herramientas de IA puedan comprender el contexto de la aplicación sin requerir una cantidad excesiva de tokens.

Saavedra aprovecha este código explícito como uno de sus principios fundamentales de flujo. Mediante el uso del Repository Pattern en el backend, la arquitectura se divide en capas concretas, permitiendo separar la lógica de negocio de los mecanismos de persistencia y acceso a datos.

En este sentido, Saavedra prioriza la sencillez del código y acepta cierto grado de repetición cuando esta contribuye a mantener los flujos explícitos y fáciles de comprender. Este enfoque resulta menos costoso cuando la escritura y mantenimiento del código cuentan con el apoyo de herramientas de IA generativa.

Esto no significa que Saavedra fomente el código repetitivo de manera indiscriminada, sino que lo considera una herramienta válida dentro de este contexto arquitectónico concreto.
